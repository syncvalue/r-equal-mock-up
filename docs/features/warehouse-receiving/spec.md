### 5.2 入庫と、シールの色・高額品

- **本社も保管場所の1つ**（倉庫マスタに1か所だけ）。**シールの色が紫・赤の高額品も、まず営業所と一体の倉庫に入庫**する（鑑定士は色にかかわらず同じ操作。QRの色で納入先は変わらない）。**そのあと、倉庫間移動で倉庫から本社へ移す**。本社には、入庫ではなく移動でだけ入る。
  - 色は紫（最も高額）・赤・黄・緑・青の5色だが、**高額品の判定は紫・赤だけで、黄・緑・青の扱いは同じ**（色は鑑定士・店舗スタッフが選ぶ。古い記録の「黄・緑・青」は、そのまま読める）。本社へ移す色は倉庫マスタ画面で変更できる。
  - 色は基本的に鑑定士が決める（査定部と相談することもある）。
  - 1契約に高額品とそれ以外が混ざっても、全て同じ倉庫に入庫し、高額品だけを後で本社へ移す。
- **入庫の規則**: 色にかかわらず、**倉庫の担当が入庫する。本社には入庫できない**（本社の倉庫担当の入庫タブは、入庫できない旨が出る）。**倉庫間の移動の規則は、これまでどおり**（高額品は本社だけへ、高額品以外は本社以外の倉庫だけへ移せる）。
- **倉庫担当の入庫**: 契約ごとに、明細と実物を見比べて、一致した商品に☑を付けてから入庫。☑は誰がいつ付けたかが残る。スキャナ・手入力（シールNo.）の場合は「読み取りで照合した」記録。誰が買い取った商品でも入庫できる。**保管場所は、訪問買取は「クーリングオフ保管棚」に固定**（棚は選ばない）。**店頭買取（クーリング・オフの対象外）だけ、入庫先の棚を選ぶ**。
- **鑑定士の入庫**（タブレット）: 最初の操作は、**商品に貼ったシールのQRの読み取り**（画面の最上段の大きなボタン。QRが読めないときだけ、下のシールNo.入力）。自分の商品を、**納入先の倉庫は選ばず**、自分の営業所と一体の倉庫（なければ先頭の倉庫）に入庫する。**画面は、左に一覧・右に入庫の操作ではなく、左が「入庫する」、右が一覧**。**入庫した商品は一覧から消さず、グレーの「入庫済み」にして、各訪問の下へ回す**（上が未入庫、下が入庫済み。未入庫が残る訪問が先）。**保管場所（棚）は選ばない**。クーリングオフ期間中は商品ごとに分別せず、**全て「クーリングオフ保管棚」にまとめて保管**する。この場合、倉庫での照合の記録は残らない。入庫済み・他の鑑定士の商品・未登録のシールはエラー。手元にない商品は「所在不明」として報告できる。対象日で絞り込み（1日分でも、2〜3日分まとめてでも可）。
- **シールの貼り替え**: 色が間違っていた場合（新しいシールのQRから色が自動で選ばれる）、**シール自体が別になるので、商品のシールNo.（ID）も新しくなる**。古いNo.・色は履歴に残り、移動などの記録は新しいNo.に引き継がれる。古いシールを読み取ると、貼り替え済みと新しいNo.が出る。**貼り替えられるのは、入庫前・所在不明・在庫の商品のみ**（出品中・委託中・売却済み・返品対応中・輸送中は不可）。納入先が変わる場合は、倉庫間移動で本社・倉庫に移すよう案内する。鑑定士は訪問を終える前なら、タブレットでシールを「解除」して読み取り直す。

### 1.8 商品の入庫

→ 詳細は 5.2。鑑定士が自分の商品を、営業所と一体の倉庫へ入庫する（納入先は選ばない）。**高額品（紫・赤）も、ほかの商品と同じようにタブレットから所属の倉庫に入庫する**（一覧に「高額品（あとで本社へ移動）」と出る）。本社へは、倉庫の担当が倉庫間移動で移す。
