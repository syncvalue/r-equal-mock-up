### 2.3 配車確定（配車係）

- 鑑定士ごとの列のカレンダーのみ（一覧表示は廃止）。**予約をドラッグして鑑定士・時間を調整**できる。鑑定士の元からの予定も予約として取り込んで動かせる。
- **帯を押すと、その予約の詳細が、画面の右側（表の横）に出る**（訪問カレンダー 2.7 の週の表と同じ。下には出さない）。詳細の上のほうに、確定／仮に戻す・詳細を変更・取消を置く。**詳細は、確定の判断に要るので、受付で登録した内容をすべて出す**（訪問カレンダーの詳細と同じ項目。フリガナ・性別・年齢・郵便番号・電話番号・受付日時と受付者・来電のきっかけ・売りたいもの・大型品・立会い・同席者・駐車スペース・表札・前日確認の連絡時間・訪問時の注意など）。**項目は、意味ごとの枠（訪問／お客様／売りたいもの／当日の状況／受付の記録、そのあとに お客様の実績・評価／担当と移動）に分けて、見出しをつける**（訪問カレンダーの詳細と同じ。2.7）。**選んだ帯は、黒い太枠・黄色の外枠・影で強く目立たせる**。もう一度押すか✕で閉じる。**右側のエリアは、はじめから確保しておく**（選んだときに、カレンダーが縮まないように）。何も選んでいないときは、「何もクリックされていません。カレンダーの枠をクリックすると、詳細が表示されます。」と出す。
- **顧客ランクは、新規かリピーターかとは別の軸**: 帯には、顧客ランク（「SS」とランクだけを書く。「顧客」は付けない。決まっていなければ「未設定」）と、**新規／再訪**（買取の実績・受付の記録で決まる）を、**別々の札**で出す。**新規のお客様にも、ランクを付けられる**（受付のオペレーターが推測で入れる（2.1）。配車係が、お客様の評価の登録で、付ける・直す。実績がなくても、住所などから推測してよい）。ランクは変わっていくので、**変更のたびに、変遷（ランクと日付）を残し**、お客様の詳細に出す（今後の要件 R-3）。ダミーのお客様・鑑定士は、SS・S・A・Bに、できるだけ分かれるように付けている。
- **ランクと性別が、カレンダーで分かる**: 売上のため、**高いランクのお客様には、高いランクの鑑定士を当てる**（その差配が配車係の仕事）。鑑定士のランクは**列の見出し**（色と、名前の横の札）、顧客ランクは**帯の中**（色と「A」の札）に出す（色は、次の項目）。**お客様の性別は、帯の中の記号（♀・♂）**で出す（男女比も配車の判断に使うため。性別が分からない、鑑定士の元からの予定には出ない）。
- **色はランクを表す**（**SS＝赤・S＝橙・A＝緑・B＝青**。暖かい色ほど上位。**鑑定士のランクと顧客ランクは、同じ色**: SS鑑定士とSS顧客は同じ色、S鑑定士とS顧客は同じ色…。名前の横・顧客の「SS」などの札も、同じ色。**鑑定士ごとの色分けはしない**。列が鑑定士ごとのため）: **帯の色＝顧客ランク**（買取の実績がない新規のお客様・元からの予定でランク不明のものは、白に近いグレー）、**鑑定士の列の見出し＝鑑定士ランクの色で塗る**（帯と同じ色）。見出しの名前の横の「SS」などの札も残す（見出しと同じ色だと見えないので、白地の札にする）。同じ色の帯と列を合わせれば、SSのお客様にSSの鑑定士を当てられる。**状態は枠線で表す**: 確定済み＝実線／仮確定（未確定）＝点線／確定から仮確定に戻った＝黒の二重線（ランクの色と重ならないように。変更内容は、右の詳細に表示）。凡例は、エリアの行に出す。休みと重なる予定は警告。
- 訪問間の移動距離と、鑑定士ごとの1日の総移動距離を表示（配車係の鑑定士の列の見出しには、「走行距離：3.4km」だけを書く。時間は出さない。**走行距離を押すと、その日の訪問ルートの地図（モーダル）が開く**: 訪問の場所にピンを立て、**訪問する順（開始時刻順）に①②③の番号**を振り、順に線（点線）でつなぐ。右に、番号つきの訪問の一覧（時間・お客様・住所・前の訪問からの距離）を出す。**仮確定のピンは、白地に点線の枠**。線は、ピンどうしを結ぶ直線で、道路に沿ったルートではない。**モックのため、ピンの位置は住所からの概算**（本実装は、Googleマップの住所検索の座標と、道路のルート検索を使う）。画面ID: CC-M07。**見出しの鑑定士名は苗字だけ。その日の件数は出さない**。この画面だけの扱い）。鑑定士のランクと今月の担当件数の偏りを見て判断する。
- **お客様の詳細モーダル**（配車係が誰を当てるかを判断する材料）: 買取履歴（品目ごと全件・折りたたみ）、鑑定士の評価・メモ（訪問ごと）、前回までの担当、ランク・厄介度・クーリングオフ歴、見送り品。
  - **顧客ランク**（SS・S・A・B）: 登録がなければ、**総買取額から自動**（**区切りは仮**: 100万円以上=SS、50万=S、20万=A、実績あり=B、なし=ランク未設定。新規のお客様でも、配車係が登録すればランクが付く）。鑑定士のランクと同じ4段階で、**SSのお客様にはSSの鑑定士を当てる**のが基本。
  - **厄介度**（なし/注意/要注意）: **人が登録したものだけ**。鑑定士の評価から自動で上げない（自動判定は廃止した）。
  - **クーリングオフ歴**は契約の記録。お客様の評価を登録し直しても消えない。
- **配車係の権限ルール（重要）**: 確定権があるので、**配車係が何を入力・変更しても、状態は変えない**（確定済みは確定のまま）。お客様に連絡して回答次第で決めたいときだけ、配車係が意図的に**「仮に戻す」（確認待ち）**。
- **ダミーデータの訪問先は、実在する場所の住所**（大阪城・大阪駅・なんばCITY・名古屋駅・東京タワーなど、地図で探せるわかりやすい場所。`src/landmarks.js`）。**座標も、その場所のもの**（概算）なので、訪問ルートの地図（上）のピンが、実際の場所に立つ。お客様の氏名・電話は架空。受付で、これ以外の住所を入力したときは、これまでどおり、エリアの中心からの概算の位置になる。
- 「空き状況・受付履歴」画面は削除済み。
