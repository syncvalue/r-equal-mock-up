### 1.3 始業・終業と経費（`src/workday.js`）

**重要な決定**: 始業するまで**現地買取だけ**が使えない。他の機能は始業前・終業後も使える。

- **始業**: 前日繰越金を実際に数えて照合（**ずれがあれば理由が必須**）→ 点検8項目（飲酒・体調・身だしなみ・社員証・車両・タブレット・買取用資材・本社からのお知らせ）をすべてチェック → 記録して業務開始。
- **補充の依頼**（`src/advanceRequest.js`・`src/advanceView.js`、保存は `rq-mock-advance-requests`）: 鑑定士の**経費管理の画面には、「補充を依頼する」のボタンだけを置く**（やり取り中の件数・経理部からの新着の件数つき）。押すと**モーダル**が開き、**新しい依頼（金額（必須）・理由（任意））**と、**これまでの依頼の一覧（やり取り中／完了）**、選んだ依頼の**経理部とのチャット**が出る。依頼を送ると、依頼の内容が、チャットの最初の発言になる。**実際の振込は銀行システムで行うので、画面には、振込済み・却下・振込金額は出ない**（チャットで、金額などを相談する）。**やり取りが終わったら（振り込まれても、見送りになっても）、依頼を出した鑑定士が「✓ 完了にする」を押す**（完了すると、チャットは続けられない。完了の記録がチャットに残る。経理部は完了にできない）。経理部のメッセージが届くと、タブレットにトースト（開いたままでも反映）。チャットは、経費精算のチャット（4.2）と同じ仕組みで、**依頼ごとに1つ**（鑑定士は左、経理部は右）。**鑑定士の所持金に補充金が入るのは、経理部が補充金を入力し、鑑定士が引き出し金額を登録してから**（下。依頼とは別の操作）。
- **所持金（財布は1つ）** ＝ **入り**（前日繰越金 ＋ 引き出し金額）− **出**（経費・買取代金）。小口金のような別枠はない。**補充金は、引き出すまで所持金に入らない**（鑑定士タブレットの経費管理では、補充金のカードを**「振込済み・引き出すまで所持金ではありません」と表示し、未引き出しがあれば黄色の枠＋「未引き出し ¥n」**、上部に**補充金のお知らせ（「未引き出し分を、引き出した」ボタンつき）**、入出金の行に**「未引き出し／引き出し済み」の印**を出す。**ヘッダーに点滅する「補充金 未引き出し ¥n」、メニューの経費管理に「未引き出し ¥n」、☰の点、タブの題名の「(n)」**で、引き出し忘れを防ぐ。引き出し金額を登録して、はじめて所持金に加わる）。補充金は経理部が入力し、**引き出し金額は鑑定士が経費管理の画面で入力する**（通常は一致。一致しないときは、鑑定士の画面・日報・経理部の確認事項に出す）。毎朝の定例の補充金（30万円）はダミー（自動で振り込まれる）。繰越金の初期値は5万円。`withdrawalsOf`・`addWithdrawal`・`summaryOf` の `undrawn`（補充金−引き出し金額）。
  - **未始業の鑑定士にも、前日繰越金は手元にある**ものとして扱う（経理部の画面でも同様）。
- **経費**: 種別（ガソリン代・昼食代・備品購入・高速/駐車場・交通費・その他）＋金額＋レシート写真。レシートはAIで読み取り、種別・金額・内容を自動入力（人が確認・修正できる前提。撮影が先頭）。**インボイス対応**のチェック欄がある（適格請求書のレシートか。経費に記録し、一覧に「インボイス」と出す）。**OCRでレシートに適格請求書発行事業者の登録番号（T＋数字13桁）が読み取れたら、自動でチェックする**（読めなくても、人がつけたチェックは外さない。再読取は読取結果に合わせる）。`isInvoiceNo`・`invoiceAfterRead`。経理部の経費精算の画面には、まだ出していない（経費の明細に「インボイス」と出すだけ）。数字は右詰め。
- **買取代金は、訪問終了時に経費として自動計上**される（所持金から減る）。経費の集計・「高額」判定からは除外される。
- **終業**: 帳簿残高と実際の現金を照合（ずれは理由必須）→ 終業点検4項目 → 日報提出。**実際の現金は、紙幣・硬貨ごとの枚数（1万・5千・2千・1千円札、500・100・50・10・5・1円玉）で入力し、合計が「実際の所持金」になる。数えた現金の写真が必須**（なければ提出できない）。枚数と写真は日報に残る（`DENOMINATIONS`・`cashTotal`）。日報の**経費の内訳**に、種別ごとの合計と並べて**経費の明細とレシート画像**（鑑定士が計上したもの。買取代金の自動計上は除く。レシートのない経費は警告）を出し（提出後の日報にも残る）、終業点検の1項目目「経費の履歴とレシート画像を見直し、間違いがない」で確認する。始業時の現金確認は、これまでどおり金額の入力のまま。日報には現金収支・経費内訳・訪問と買取の実績が自動集計される。**終業後は、現地買取と経費の計上ができない**（ただし、**営業サポートがチェック済みにするまでは、提出した日の経費を直せる**。4.2）。翌日の繰越金は、終業時に数えた金額。
- **訪問できなかった場合**: 不在／日程変更の依頼／お客様都合のキャンセル／その他（その他はメモ必須）。**訪問実績には数えるが、鑑定士の責任ではないため業績（成約率など）に影響しない**。日報・本社画面に反映される。
