### 1.6 現地買取の流れ（`src/views.js` の `STEPS`）

訪問開始 → お客様確認 → 説明事項 → 買取明細 → 買取商品の確認 → シール紐づけ → 送信・終了

0. **訪問開始**（到着の確認）: **訪問先を中心にした周辺地図**（OpenStreetMapのタイル、`src/mapView.js`）に、**自分の現在地（青い点）**を重ねて出す。現在地が近ければ入る縮尺（16〜13）で一緒に出し、**離れていれば訪問先を優先して中心のまま**、現在地は出さずに「訪問先の○○、約○kmにあります（まだ着いていません）」と示す。**地図の訪問先の印（「タップで訪問開始」）をタップすると、訪問開始**（専用の「訪問開始」ボタンはない。地図は画面の高さいっぱいに大きく出す）。現在地は、この画面を開くたびに取り直す（許可されない場合は、現在地なしで訪問先だけ出す）。
1. **お客様確認**: 初めて／リピーター（何回目）を表示。リピーターは過去の買取履歴・評価を確認できる。
2. **説明事項**（査定前に必須）: 6項目（買取の流れ・断れること・撮影と写真送信の了承・本人確認の必要性（古物営業法）・クーリング・オフ・**やり取りの録音の了承**）を説明してチェックし、**他商品を提案してよいか**をお客様に確認する。両方済み、**録音を開始する（または登録済み）まで、次へ進めない（録音は必須）**。
3. **買取明細**: 商品マスタから選択／AIカメラ／査定部への査定依頼／AI査定。金額は通貨形式（¥・円・3桁区切り）。明細の段階でもシールを貼りながら進められる。
   - **商品の写真は必須**: 買取商品ごとに、**写真を1枚以上**登録しないと次へ進めない（進めない理由は、フッターに「写真が未登録の商品がN点あります」などと赤字で出す。複数枚OK、1枚ずつ削除できる。商品の詳細モーダルで撮影・追加）。明細の行に写真の枚数（なければ「写真なし」）が出る。査定依頼の写真（任意）とは別。**店舗（店頭買取）は、まだ対象外**。
   - 査定依頼（任意）は、商品ごとの**チャット**。最初の依頼は、状態・補足の文章か写真のどちらかがあればよい（**写真は任意**）。査定員の返信（コメント・提案額）に、鑑定士が続けて返信できる（文章または写真）。1回で終わらなくてよい。査定員の返信が未読の商品には、未読の印が出る。提案額は、返信ごとの「買取金額に反映」で取り込む。
   - 明細の行には、査定依頼の状態（査定中・返信あり・査定完結）が出る。
4. **買取商品の確認**: **お客様に見せる画面**（文字は大きめ）。承認済みと確認中を一目で区別。**査定部の承認が必要**。承認後に金額・ランク・数量が変わったら、再承認が必要（`stale`）。**査定依頼を出した商品は、その査定依頼が完結するまで承認されない**（依頼がない商品は関係なし）。
5. **シール紐づけ**: 商品1点（数量があれば1個ずつ）にシールのQRを読み取って紐づける（カメラ起動はモック）。**シールの色（紫・赤・黄・緑・青）は、QRを読み取ると自動で選ばれる**（シールNo.の「RQ-」の次の1文字が色: P紫・R赤・Y黄・G緑・B青。QRから分からない古いシール・手入力のときは、画面で色を選ぶ。色が決まらないと次へ進めない）。黄・緑・青は、色は選ぶが、**扱いは同じ**（高額品かどうかは紫・赤だけ）。古い記録の「黄・緑・青」（色を分ける前）は、そのまま読める。同じシールを別の商品に使うとエラー。
6. **送信・終了**: 訪問終了前チェックリスト（本人確認書類の登録・契約書の印刷と紙の署名・会社控えの回収・クーリング・オフ説明・代金のお支払い・書類・端末などの忘れ物の6項目）と、**持ち帰りの箱詰め**。GMOサインへ送信して訪問終了。**誤タップを防ぐため、「訪問終了」を押すと「訪問を終了しますか？」の確認（はい・いいえ）が出て、「はい」で終了する。**
   - **持ち帰りの箱詰め**（`src/packing.js`）: **買い取った商品の忘れ（持ち帰り忘れ）と、買い取っていない商品の持ち帰りを防ぐ**ため、持ち帰り用の箱に、**買い取った商品のQRコード（シール）を1点ずつ読み取りながら入れる**。対象は、シールを貼った、売る商品（数量があれば1点ずつ。**見送り品は対象外**）。**すべて箱に入るまで、訪問を終了できない**（箱に入っていない商品が、画面に出る）。**買い取っていないQR（別のお客様の商品・見送り品など）を読み取ると、警告が出て、箱には入らない**（「箱に入れず、お客様にお返ししてください」）。同じQRを2回読み取ると、「すでに箱に入っています」。これは、これまでの「梱包した」「数量が一致」の手入力のチェックの代わり（自動）。QR読取はモック（カメラ画面は演出）。デモ用に、買い取っていない商品を読み取るボタンと、「すべてチェック」で箱詰めも済ませるボタンがある。
   - 契約書は、GMOサインで印刷する。**チェック項目・署名は、印刷した紙にお客様が記入する**（電子署名ではない）。
   - 訪問終了時に、シール付きの実物1点ごとに「入庫待ち」が登録される。
   - **やり取りの録音**（`src/recording.js`・`src/recordingStore.js`）: 説明事項で録音の了承にチェックすると、ヘッダー（または送信・終了の画面）の「録音を開始」で、ブラウザのマイク録音（MediaRecorder）が始まる。録音中は「● 録音中です」と出る。**「録音を停止して、システムに登録する」で停止すると、録音データ（IndexedDB）と記録（訪問ID・鑑定士・お客様・時間・サイズ）が登録される**。録音中に「訪問終了」を押しても、自動で停止して登録してから終了する。登録した録音は、今日の予定の訪問結果で再生できる。録音中は画面を消さない（Wake Lock）。マイクの許可・HTTPS（localhost可）が要る。
   - **査定したが売らなかったもの（見送り品）**を記録できる（売らなかった理由は聴取しない＝記録しない）。
