## 1. 鑑定士タブレット（`/tablet/`）

### 1.1 ログイン

- ID・パスワード → SMS認証コード（2要素認証）。パスワード再設定もSMSコードで本人確認する。
- コードは6桁・有効5分・再送は30秒待ち・入力ミスは3回まで（`src/auth.js`）。
- パスワード条件: 8文字以上・英字と数字を含む・IDと同じ不可。
- 存在しないIDでも、画面上は同じように進める（ID有無を知られないため）。
- モックのため、IDは何でも可。既存IDならその鑑定士、それ以外は先頭の鑑定士（鈴木 一郎）としてログイン（デモ用アカウントは `sales01`〜）。
- **初期画面は状態で切り替わる**: 未ログイン→ログイン、始業前→始業、始業済み→ダッシュボード。データ初期化でログイン状態も破棄。

### 1.2 メインメニュー（左の開閉式ドロワー）

ダッシュボード／始業／今日の予定／顧客検索／経費管理（**入り＝前日繰越金・補充金、出＝経費・買取代金**。1.3）／商品の入庫／終業・日報。
始業と終業・日報は別項目で、状況に応じて活性・非活性が切り替わる。**現地買取はメニューに出さない**。入り口は今日の予定（予定を選んで「この訪問を開始」。訪問中は同じ予定に「訪問に戻る」）。
