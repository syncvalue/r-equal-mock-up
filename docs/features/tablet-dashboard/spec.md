### 1.4 ダッシュボード・メッセージ・業績

- 本社からのメッセージとグループリーダーからのメッセージを、別枠・開閉式で表示。枠は2件分の高さに固定し、詳細はモーダル。「他○件あります」を表示。重要フラグ・既読管理あり。宛先は「全員」または「グループ」。
- **業績ダッシュボード**: 今日／今週／今月。訪問数・契約数・買取額・成約率・平均単価。月間目標に対する進捗とペース。
  - **粗利・再訪数・年間**: 期間の指標に、**粗利**（販売代金から原価（買取額）を引いた見込み）と**再訪数**（受付の種別が「再訪」の訪問。不在・日程変更は含まない。残りは「新規」）を出す。その下に、**年間（1〜12月）の粗利と再訪数**（年間粗利・年間の再訪数の合計、月別の粗利の棒と月別の再訪数）。グループ全体のメンバー別の表にも、再訪・粗利の列がある。受付の種別は、コールセンターの受付の「新／再」（`apType`）。**粗利と種別は、いまはダミーデータ**（粗利は、買取額の18〜40%。実際の粗利は、販売代金が倉庫・物流の販売とつながってから集計する）。
  - **閲覧権限**: 一般は自分のみ。**グループリーダーはグループ全員・メンバー個別も閲覧可**（デモ用にロール切替あり）。
  - 訪問ごとの結果モーダル、期間中の日報の閲覧（リーダーはメンバーの日報も）。
  - 業績データはすべて、鑑定士×日付から決まる疑似乱数のダミー（日曜と未来日は休み扱い）。
- グループは A（東日本）/ B（西日本）、鑑定士は16名（`src/dashboard.js`）。
