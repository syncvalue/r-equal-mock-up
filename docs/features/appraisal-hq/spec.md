## 3. 査定部（`/honsha/index.html`）

- **担当**: 査定員（青木=グループA、井上=グループB。マスタ管理の社員で登録、7章）が、担当グループの鑑定士の**今日の予定（時系列）と訪問状況**を見る（デモ用に査定員を切り替え可。完了した訪問は隠せる）。**いま訪問中の予定は、行全体を緑の背景・左の太い緑の線・点滅する「● 訪問中」のバッジで目立たせる**（完了は薄く、まだは白地のまま）。
- **買取明細のリアルタイム表示**: 鑑定士が登録した商品・金額・ランク・数量・売る/売らない・本社査定の状況・コメント。**鑑定士のお客様の評価**も確認できる。
- **査定依頼のチャット**: 商品を選ぶと、鑑定士とのチャットが開く（鑑定士は左、査定員は右。写真・「既読」つき）。**普通のチャットと同じ**で、メッセージを入力して「返信する」（Ctrl+Enter でも送れる）。査定部はPCなので、**タグ・定型文のボタンはない**。任意で提案査定額（ランクは鑑定士の入力のまま）を付けられる。チャットと違うのは、査定依頼ごとに**「完結する」**操作がある点だけ。**送信フォームは1つ**（回答と意見の区別なし）。鑑定士の返信が未読の商品は、一覧に「未読あり」が出る。**査定員が「完結する」**とやり取りが終わる。完結のあとに鑑定士が続けて送ると、再開（返信待ち）になる。査定依頼のない商品へのコメントは、これまでどおり鑑定士のコメントとして届く。
- **承認／差戻し**: 鑑定士の申請は不要で、**商品が登録された時点からいつでも**実行できる。金額が入っていない商品は対象外。**査定依頼が出ている商品は、完結するまで承認できない**（ボタンは押せず、一覧には「査定の完結待ち」）。**承認の欄は、チャットの上に固定で表示**し、査定依頼が続いている間は、隠さずに**マスク**（薄く表示して操作不可）する。**差戻しも、完結してから**。依頼のない商品は、いつでも承認できる。「承認できるN件を一括承認」は、条件を満たす商品だけ。**差戻しは理由必須**で、鑑定士にはコメントとしても届く。承認後に鑑定士が変更したら再承認が必要。
- **お知らせ送信**: 全員／グループ宛のメッセージを作成して、鑑定士のダッシュボードに表示。
- 入金・日報の機能は**経理部へ移した**（査定部にはない）。
