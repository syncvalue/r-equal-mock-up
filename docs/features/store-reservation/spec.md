### 2.6 来店予約（`?tab=store`）

店舗への**来店予約**を、オペレーターが電話で受ける（`callcenter/storeTab.js`）。訪問買取の受付（2.1〜2.3）とは**別の流れ**で、**エリア判定・担当鑑定士の割り当て・仮確定・配車確定はない**（お客様が店舗へ来る側のため）。

- **項目**: 店舗（有効な店舗から選ぶ）・来店の日（今日以降）・時刻（10:00〜18:30、30分刻み）・電話番号（必須）・お名前（必須）・フリガナ・売りたいもの（**複数行で入力できる**。改行は、一覧・店舗の画面でもそのまま出る）。受けたオペレーターが記録に残る。**画面はPCの幅いっぱいに、左に入力（空き状況のカレンダーを含む）・右にこれからの来店予約の一覧**の2列で、それぞれ縦にスクロールできる。
- **空き状況のカレンダーから、来店の日・時刻を決める**: 店舗を選ぶと、その店舗の**空き状況**が、**縦=時刻（10:00〜18:30、30分刻み）・横=日付（7日）**で出る（`src/storeSlots.js`）。**空いている枠を押すと、来店の日・時刻に入る**（日の入力・時刻の選択からも、これまでどおり決められ、変えるとカレンダーも合わせて動く）。枠には空きの数（空N）を出し、**予約が入っているほど濃く**、**満席は押せず**（「満」）、**過ぎた時刻（今日のいまより前・過去の日）も押せない**。◀▶で1週間ずつ、「今日」で今日からに戻れる（今日より前には戻れない）。
  - **同じ時刻に受けられる来店の数は、その店舗の有効な店舗スタッフの人数**（最低1。なんば店2・新宿店1。**モックの前提**で、本実装では、店舗ごとの受付枠の設定に置き換える）。1件の予約は、その時刻の枠だけを使う（対応の所要時間は見ない）。取消・来ず・飛び込みは数えない。
- **過去のお客様**: 電話番号を入れると、過去の買取（回数・総額・顧客ランク・厄介度・クーリングオフ歴）があれば、その場で出る（訪問買取の受付と同じお客様の履歴を使う）。
- **一覧**: これからの来店予約を、日ごと・時刻順に出す（全店舗）。**取消は理由つき**（受付の取消と同じ4つの理由）で記録が残る。取消は、店舗が来店済みにする前まで。
- 予約は、店舗の画面（11章）の「これから来店の予約」に出る。**状態は「予約」だけ**で、「仮確定・確定」は使わない。
