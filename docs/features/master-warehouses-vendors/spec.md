# マスタ管理：倉庫・委託先

> 機能仕様書（分割後）。元の仕様書の章番号（7.5・7.6）は、ほかの章からの参照のため、見出しのまま残してある。用語は [用語集](../../shared/glossary.md)、全体は [INDEX.md](../../INDEX.md)。

### 7.5 倉庫

- 倉庫・物流の画面にあった「倉庫マスタ」を、ここへ移した（運用ルールは5.1・5.2のとおり）。倉庫の登録・変更・有効/無効と、**高額品の判定（本社へ移すシールの色）**。一覧には、保管中の点数・倉庫担当・営業所との関係が出る。
- 倉庫担当の登録・所属変更は、7.1の社員で行う。

### 7.6 委託先

- 業者オークションなど、委託販売の相手（業者）の登録・変更・有効/無効（名前・郵便番号・住所・電話番号）。倉庫・物流の「販売（出品）」で、委託先の選択肢になる（5.4）。
