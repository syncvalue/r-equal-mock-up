### 1.9 顧客検索（メニュー「顧客検索」、`src/myCustomers.js`・`src/customersView.js`・`src/callLog.js`）

- **目的**: 鑑定士自身が、お客様に電話して、**再訪のアポを取る**ための顧客リスト。前回の訪問から何日たっているか、いま近くにいるか、最近電話したか、を見て、連絡する相手を選ぶ。
- **対象は、自分が担当したお客様だけ**（他の鑑定士の顧客・訪問は出さない。今後の要件 R-1）。訪問した（買取・評価の記録がある）お客様。不在で訪問できなかった人は含まない。モックは記録が少ないため、鑑定士ごとに決まるダミーの顧客を補う。
- **一覧**: 氏名・フリガナ・住所・**前回の訪問日（○日前）**・自分の訪問回数・買取計・**現在地からの距離**・**直近の電話の印**。検索は氏名・フリガナ・電話番号・住所。**並び順**: 前回の訪問から長い順（初期）／**過去の買取金額順**／**買取できなかった商品数順**（査定したが売らなかった＝見送りの商品の数）／近い順／電話していない順。**買取金額・見送りの商品数は、自分の訪問だけを数える**（ほかの鑑定士の訪問の分は含めない。R-1）。**絞り込み**: 前回の訪問から30・90・180日以上、近く（5km以内）。現在地は、この画面を開いたときに取る（許可されなければ距離は出さない）。
- **お気に入りと自分用のメモ**（`src/customerNotes.js`）: 一覧の**★**、またはお客様の詳細の★で、お気に入りに登録・解除する。「**★ お気に入りだけ**」で絞り込める。お客様ごとに**自分用のメモ**を書ける（詳細のメモ欄。**入力すると自動で保存**され、一覧にも出る。検索の対象にもなる）。**一覧には、メモの先頭100文字**（超えると「…」）を出す。自分用のメモに加えて、**直近の、メモ付きの電話の記録**（電話の結果のメモ。共有される記録）の先頭100文字も、日付つきで出す。**自分用のお気に入り・メモは、自分だけに見える**（ほかの鑑定士・オペレーターには出ない。電話の記録とは別。今後の要件 R-1）。鑑定士ごとに分けて `rq-mock-cust-notes`（localStorage）に保存する。
- **お客様の詳細**（モーダル）: 基本情報（住所は地図へのリンク）、自分の訪問のまとめ、**電話をかけるボタン**（`tel:`）、**電話の結果の記録**、**電話の履歴**。
- **電話の結果の記録**: 結果は ①再訪のアポが取れた（**再訪の希望日時が必須**）②つながった（アポは取れず）③つながらなかった（不在・留守電）④今後の連絡は不要と言われた。メモは任意。**受付（日時の確定）は、これまでどおりオペレーターが行う**（鑑定士は希望日時を共有するだけ）。
- **電話の履歴は、オペレーターを含む他の人にも見える**（お客様から見れば、誰がかけても同じ電話。しつこいと思われないように）。コールセンターの**受電履歴**（2.1）に、「**鑑定士が架電**」として出る。受電履歴には、**前日確認の電話**（オペレーター、2.7）も出す。鑑定士の画面の電話の履歴にも、オペレーターの電話が出る。**履歴の1件ごとに、受電（お客様から）か架電（こちらから）か、誰が（オペレーターか鑑定士と名前）、何の目的か（訪問の予約・予約の変更・予約の取消・問い合わせ・前日確認・再訪の相談）が分かる**。**ほかの鑑定士の電話は、名前を伏せて「鑑定士（ほかの担当）」と出す**。
- **しつこい電話の防止**: 7日以内に電話した記録（誰が電話したかを問わない）があれば、一覧に⚠、詳細に注意を出す。「今後の連絡は不要」の記録があれば、詳細に赤い警告を出す（電話はできるが、控える）。
- 電話の記録は `rq-mock-call-log`（localStorage）。本実装では、サーバーで共有する。
