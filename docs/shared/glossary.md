## 用語集（表記の統一）

同じものを指す言葉が画面や資料でバラバラにならないよう、**使う語**を決めています。「使わない語」を見つけたら直し、新しい語を足すときは、先にここに載せてください。

### 会社・部署・社員・役割

| 使う語 | 意味 | 使わない語・注意 |
|---|---|---|
| **会社** | クライアントの「REqual」**1社だけ**。複数の会社は持たない（部署は、すべてこの会社に属する） | |
| **部署** | 会社の中の組織の単位（営業部・コールセンター・査定部・経理部・物流部など）。**並べるだけで、階層（課・チーム）はない** | 「所属」だけで部署を指さない（所属＝社員が部署・倉庫に属すること） |
| **社員** | このシステムを使う**社内の人**。**いずれかの部署に属し**、1人にひとつの**役割**を持つ。マスタ管理（7章）の社員で登録する | **ユーザー**（以前の呼び方）、スタッフ。お客様は含まない。**コードの `USERS`・`userId`（`src/dashboard.js` など）は鑑定士だけを指す古い名前**で、社員全体の名簿は `src/employees.js` |
| **役割** | 社員のシステムでの立場。鑑定士・オペレーター・配車係・査定員・経理担当・倉庫担当・店舗スタッフの7つ（**役員・社長・システム管理者の3つを、追加する予定**。モックでは未実装。[今後の要件 R-4](../FUTURE_REQUIREMENTS.md)）。**役割で、使う画面が決まる。部署とは別の項目**（例: コールセンターの部署に、オペレーターと配車係がいる） | ロール（権限の細かい設定は、本実装の課題） |
| **アクター** | このシステムを使う人の立場。**役割と同じもの**を指す（7つ）。役割ごとの、使える機能は [actors.md](actors.md) | ユーザー |
| **区分（一般・責任者）** | 役割の中の区分。**責任者**は、その役割のまとめ役。**役員・社長・システム管理者には区分がない**。役割ごとの使える機能は [actors.md](actors.md)（2026-11-19 に追加。責任者ができることは、まだ仮） | 管理職、リーダー（単独） |
| **役員・社長** | 経営の状況を見る人。区分なし。**閲覧のみ**（仮）。専用の画面は、まだない | |
| **システム管理者** | マスタ（社員・部署・営業所・出張・店舗・倉庫・委託先）と、システムの設定を管理する人。区分なし。マスタ管理の画面を使う | 管理者（単独）、マスタ管理者 |
| **鑑定士** | お客様の自宅へ行き、**現場で買取をする人**。鑑定士タブレットを使う。経費を使うのも鑑定士。**2026-11-05 に、以前の呼び方「営業」から改めた**（営業所・営業部・営業時間・古物営業法の「営業」は、そのまま）。コードの `sales`（役割）・`USERS`・`userId` は古い名前のまま | **営業**（以前の呼び方）、営業マン、営業員、営業担当、担当者 |
| **グループリーダー** | 鑑定士のうち、グループ全員の業績を見られる人（役割ではなく、鑑定士の属性） | 「リーダー」と略さない |
| **担当鑑定士** | 受付・訪問ごとに割り当てた鑑定士。**お客様には名前を伝えない** | 担当営業、営業担当 |
| **オペレーター** | コールセンターで電話を受け、**仮確定まで**行う人 | オペレータ、受付者、受付担当 |
| **配車係** | 仮確定された訪問を**最終確定**し、鑑定士の割り当てを調整する人 | 配車担当 |
| **査定員** | 査定部の人。**本社にいて、現場の鑑定士から送られてきた情報（査定依頼）をもとに、リモートで査定する**。査定依頼に回答し、買取を承認する。**現場には行かず、経費は使わない** | 査定担当、査定部の担当者、鑑定士（現場の人の語） |
| **査定依頼** | 鑑定士が、商品の査定を査定部に頼むこと（**任意**）。商品ごとに、鑑定士と査定員の**チャット**（やり取り）が続き、査定員が**完結**する。状態は、依頼中（査定員の返信待ち）・回答済み（鑑定士の返信待ち）・完結 | 本社査定、本社への査定依頼 |
| **完結** | 査定員が、査定依頼のやり取りを終えること。**商品の承認の条件**（査定依頼があるとき）。完結のあとに、どちらかが話すと再開する | 完了（クーリング・オフの完了などと区別） |
| **経理担当** | 経理部の人。入出金・補充金・経費精算・固定費を扱う | 経理部の担当者 |
| **営業サポート** | 鑑定士の経費の**一次チェック**（経費精算）をする人。**2026-11-05 に追加**。いまは**役割としては分けず、経理部の画面（経費精算）で操作する**（役割・名簿・ログインの区別は、本実装の課題） | 営業事務、サポート担当 |
| **倉庫担当** | 倉庫・物流の画面を使う人。いずれかの倉庫に所属する。**本社に所属する人も倉庫担当** | 担当者（単独）、倉庫の担当者、本社担当、スタッフ |
| **店舗スタッフ** | 店舗の画面を使い、**来店したお客様の受付と、店頭買取**をする人。いずれかの店舗に所属する。鑑定士と違い、お客様の自宅へは行かない | 店員、店舗担当、販売員（買取が仕事なので）、鑑定士（鑑定士は訪問する人） |

- **「担当者」は単独で使わない**。人を指すときは、必ず役割名（鑑定士・オペレーター・査定員・倉庫担当…）で書く。
- 受付を取ったオペレーターの項目名は「オペレーター」（以前の「受付者」は使わない）。

### 組織・場所

| 使う語 | 意味 | 使わない語・注意 |
|---|---|---|
| **営業所** | 鑑定士が所属する拠点（大阪・兵庫・京都・関東・東海）。営業所ごとに担当エリアを持つ | 拠点、支店 |
| **担当エリア（エリア）** | 営業所が受け持つ都道府県の範囲。お客様の住所から判定する。画面では「大阪エリア」のように書く（営業所の短い名前は「大阪」） | |
| **出張** | 営業所のない都道府県へ、チラシを配って、**期間を決めて訪問買取をする**営業方法。**出張エリア（担当の都道府県）＋期間＋出張メンバー**で1件。マスタ管理（7.4）で登録する | バーチャル営業所（営業所は常設の拠点なので、出張とは別の語） |
| **出張エリア** | 出張の担当の都道府県。**期間中だけ**、お客様の住所から判定するエリアに加わる。画面では出張の名前（「福岡出張」）で書く | |
| **出張メンバー** | 出張に行く鑑定士。**本来の営業所は変わらず**、期間中だけ出張エリアの候補にも加わる。画面では「出張中」の印が付く | 出張者、応援 |
| **店舗** | **お客様が買取希望品を持ち込む**常設の実店舗。名前は「店」を付けない短い名前（なんば）で、画面では「なんば店」。**営業所とは別のもの**（営業所＝鑑定士が所属する拠点、店舗＝お客様が来る拠点）。マスタ管理（7.7）で登録する | 実店舗（説明の文では可）、支店、営業所（店舗は営業所ではない） |
| **グループ** | 鑑定士の編成（A=東日本、B=西日本）。営業所とは別の軸 | |
| **倉庫** | 商品を保管する施設。営業所とは独立 | |
| **マスタ** | 各画面で使う基本のデータ（社員・部署・営業所・出張・倉庫・委託先。会社はREqual固定）。管理する画面は「マスタ管理」（7章） | マスターデータ |
| **本社** | 組織としての本社（査定部・経理部がある）。倉庫マスタ（マスタ管理の倉庫）に登録した、高額品の保管先も「本社」という名前なので、**保管場所のことは「本社（保管場所）」と書いて区別**する | |
| **査定部・経理部** | 本社の部署。画面名も「査定部」「経理部」（「本社 査定部」「本社 経理部」とは書かない） | 本社 査定部、本社 経理部 |
| **コールセンター** | オペレーターと配車係が使う画面（受電・訪問カレンダー・配車確定・クーリングオフ・来店予約） | |

### 業務の言葉

| 使う語 | 意味 | 使わない語・注意 |
|---|---|---|
| **お客様** | 商品を売ってくださる人（買取の相手） | お客さま、客。**顧客**は、「顧客ランク」「顧客履歴」など、複合語のときだけ |
| **購入者** | 倉庫が商品を売る相手（フリマ・業者への販売） | お客様とは別。買い手 |
| **委託先** | 業者オークションなど、委託販売をお願いする業者 | |
| **店頭買取** | **お客様が店舗に商品を持ち込む**買取。店舗スタッフが、来店の受付から代金のお支払いまで行う（11章）。**クーリング・オフの対象外**（法律上、対象は訪問購入のため）。商品には、10日間の保管期間（5.7）がない | 持込買取、店買取 |
| **訪問買取** | 鑑定士が、お客様の自宅へ行って行う買取（鑑定士タブレットの「現地買取」の流れ）。店頭買取と区別するときの言い方 | 出張買取（「出張」は別の意味。上の「出張」の行） |
| **来店** | お客様が店舗に来ること、またはその記録。状態は**予約・待ち・対応中・完了・取消・来ず**。来店予約と飛び込みがある | 来客、入店 |
| **来店予約** | 店舗への来店を、**コールセンターのオペレーターが電話で受ける**予約。店舗と日時を決めるだけで、**エリア判定・担当鑑定士・仮確定・確定・配車はない**（状態は「予約」だけ） | 店舗アポ、予約（単独。コード上は reservations.js が訪問の受付を指す） |
| **飛び込み** | 予約なしで店舗に来店すること。店舗スタッフが、お名前だけで受け付けて「待ち」にする | 予約なし来店、フリー |
| **補充金** | 経理部が、買取資金として鑑定士に**振り込んだ金額**（**入力は経理部**）。**2026-11-05 に、以前の呼び方「立替金」「本社からの入金」から改めた**。帳簿では「鑑定士への補充金」の支払。**鑑定士の所持金に入るのは、鑑定士が引き出した分** | **立替金**（以前の呼び方）、本社からの入金、鑑定士への入金 |
| **補充の依頼** | 鑑定士が、買取資金が足りなくなりそうなときに、**経理部へ補充金の振込を頼むこと**（鑑定士が鑑定士タブレットの経費管理から出す。金額・理由（任意））。**やり取りは依頼ごとのチャット**。**実際の振込は銀行システムで行うので、このシステムは、振込の金額・結果を扱わない**。管理するのは、**やり取り中／完了**だけ（振り込まれても、見送りになっても、やり取りが終わったら完了）。**完了にできるのは、依頼を出した鑑定士**。**補充金そのものではない**（補充金の入力は、経理部が残高・入出金管理で行う）。**2026-11-05 に追加** | 補充申請、入金依頼 |
| **引き出し金額** | 補充金のうち、鑑定士が**実際に引き出した金額**（**入力は鑑定士**）。引き出した分が、鑑定士の所持金になる。**通常は、補充金と同じ金額** | 入金（所持金に入る金額の意味で） |
| **一次チェック**（**精算**） | 営業サポートが、**日ごと・鑑定士ごと**に、前日までに提出された経費・お客様への支払・現金（前日繰越金と終業時の所持金）の**入力漏れ・入力ミス**を確認すること。画面名は「経費精算」。問題なければ**チェック済み**、あれば**差戻し**（理由必須）。状態は、未チェック・チェック済み・差戻し。**一次チェックの先（二次チェック・帳簿への反映）は、まだ決めていない** | 承認（査定部の承認と区別）、精算済み・未確認（以前の状態名） |
| **固定費** | 毎月決まって払う費用（家賃・人件費・水道光熱費・通信・システム費など）。経理部が登録し、支払日に支払う | |
| **所持金** | 鑑定士が現場で持つ現金。**財布は1つ**（小口金のような別枠はない）。**入り＝前日繰越金＋補充金（引き出した分）、出り＝経費（ガソリン代・備品など）と買取代金の支払い**。すべて、経費管理で記録する | **小口金**（**2026-11-05 に廃止**。道具・交通費なども、経費管理の経費として、レシートつきで計上する）、査定員の小口金 |
| **粗利** | 販売代金から、原価を引いた額。週間収支で集計する | |
| **受付** | お客様の電話を受けて作る記録（ヒアリング内容と、仮確定・確定の状態を持つ） | アポ、アポイント。**予約**は、コード上の名前（`reservations.js`）と古い文言で、新しく書くときは「受付」にする |
| **訪問予定** | これから訪問する受付（訪問日が今日以降）。受電画面で、同じ番号の訪問予定を出し、変更・取消する | これからの予約 |
| **顧客ID** | お客様を1人に決める番号（C＋6桁）。**システムが自動で採番**する。**電話番号ではなくIDで一意**にする（2.1） | 顧客番号 |
| **訪問** | 鑑定士がお客様の自宅へ行って買取をすること、またはその予定。**確定した受付が、鑑定士の予定の訪問になる** | アポ |
| **前日確認** | 訪問の前日に、**オペレーターが、お客様へ1人ずつ電話**で、訪問の日時などを確認すること。連絡したか・つながらなかったか・お客様から告げられたことを、訪問ごとに記録する（2.7）。受付のときに聞く「前日確認の連絡時間」（ヒアリング項目）は、この電話をかける時間帯 | 事前連絡、リマインド、アポ確認 |
| **休み** | 鑑定士が働かない時間。**1日中休む日も、出勤する時間の外（夕方から出勤・15時まで、など）も、同じ「休み」と呼ぶ**。カレンダーでは、斜線の「休み」で表す（終日休みの日は、列全体）。休みの時間には、訪問を入れられない（2.2） | 欠勤、午前休、午後半休、午後出社 |
| **仮確定** | オペレーターが日時と担当鑑定士を仮に決めた状態。鑑定士の予定にはまだ出ない | |
| **確定** | 配車係が最終決定した状態。鑑定士の予定に出る。**オペレーターの操作には使わない**（オペレーターは「仮確定」） | |
| **契約** | 1回の訪問での買取契約。お客様と買取日でまとめる単位。商品の一覧は「明細」 | |
| **入庫** | 買い取った実物を、倉庫（本社を含む）に入れること。鑑定士タブレットのメニュー名も「商品の入庫」 | 納品、入荷 |
| **シール** | 商品1点に貼るQR付きのシール。番号は「シールNo.」。色は紫・赤・黄・緑・青 | ラベル、タグ |
| **クーリングオフ保管棚** | 訪問買取の商品を、10日間のクーリングオフ期間中、**商品ごとに分けずにまとめて保管する専用の棚** | |
| **高額品** | シールの色が紫・赤の商品。**いったん所属の倉庫に入庫し、倉庫間移動で本社（保管場所）へ移す** | |
| **見送り品** | 査定したが、お客様が売らなかった商品 | |
| **クーリングオフ** | 社内の画面・仕様での表記 | **法令・契約書・お客様への説明の文言だけ、法令の表記「クーリング・オフ」**を使う（鑑定士の説明事項、GMOサインの契約書、本社のお知らせ） |
| **顧客ランク** | お客様の資産・売却の見込み（**SS・S・A・Bの4段階**。SSが最上位）。**新規かリピーターかとは別の軸で、新規のお客様にも付ける**（今後の要件 R-3）。鑑定士のランクとは別 | お客様ランク、お客様のランク |
| **ランク（鑑定士）** | 鑑定士の等級（**SS・S・A・Bの4段階**。SSが最上位。仮の設定） | |
| **厄介度** | お客様の扱いにくさ（なし／注意／要注意）。人が登録したものだけ | |
