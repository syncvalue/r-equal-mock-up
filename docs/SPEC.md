# 出張買取アプリ（モックアップ）機能仕様書

このリポジトリを引き継ぐ方向けに、これまでの依頼内容を機能ごとに整理した仕様書です。
**「なぜそうしているか」（業務上の前提・決定の経緯）を中心に**まとめています。コードを読めば分かることは省き、迷いやすい点を残しています。

> **2026-11-18 に、この仕様書を、機能別のファイルに分割した**（内容は変えていない）。バックエンド（API）を足していくとき、機能ごとに独立して実装でき、Claude Code が、触る機能の文書だけを読めば済むようにするため。**この文書は、入口だけ**で、仕様の本文は次のとおり。
