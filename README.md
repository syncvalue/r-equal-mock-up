# 出張買取アプリ（モックアップ）

出張買取の営業担当がタブレットで使う業務アプリのモックです。Vite + vanilla JS + Tailwind CSS（CDN）。
データはブラウザの localStorage に保存され、外部へは送信されません。

## 起動

```
docker compose up --build   # http://localhost:5173
```

Docker を使わない場合は `npm install` のあと、開発サーバーを起動します（`package.json` の dev スクリプト）。
Tailwind は CDN 読み込みのため、ネット接続が必要です。

## 画面

| 画面 | URL | 内容 |
|---|---|---|
| 買取アプリ（タブレット） | `/` | 現地買取の一連の流れ、メインメニュー（準備中の機能あり） |
| 本社 査定部（PC） | `/honsha/index.html` | 買取明細のリアルタイム表示、査定依頼への回答、承認、コメント送信 |
| GMOサイン（ダミー） | `/gmosign/index.html` | 本人確認書類の登録、署名・契約締結、契約書PDF（A4）の印刷 |

3つの画面は同一ブラウザの localStorage を介して連携します（別タブで開いて確認します）。
各画面の下部にある「（デモ用）データ初期化」で、マスタ以外のデータを消せます。

## 現地買取の流れ

お客様確認 → 買取明細（商品マスタから選択／AIカメラ／本社査定／AI査定）→ 取捨選択（査定部の承認が必要）→ シール紐づけ → GMOサイン送信・訪問終了

## 構成

- `src/` 買取アプリ（`main.js` 状態・イベント、`views.js` 画面、`masterView.js`・`search.js` 商品マスタ検索、`ai.js` AI査定（モック）、`store.js` 画面間のデータ共有）
- `honsha/` 本社査定部の画面
- `gmosign/` GMOサイン（ダミー）と契約書の帳票
- 商品マスタ・AI査定・コールセンター受付情報は、すべてダミーデータです。
